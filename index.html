Tested Quality & Performance Recommendations

  • Desktop Workloads: Uncapped 60 FPS with DPR 2.0 achieves smooth 60 FPS under < 1ms JavaScript cost per frame.
  • Mobile Devices: Set maxDpr: 1.5 or 2.0 to bound drawing buffer fillrate on high-density OLED/Retina screens.
  • Constrained / Low-Power Mode: Use fpsLimit: 30 or resolutionScale: 0.75 for battery savings with no perceptible artistic degradation.
  • Accessibility & Contrast: Mark canvases decorative (aria-hidden="true", role="presentation", tabindex="-1"). Foreground text must satisfy WCAG AA 4.5:1 contrast against both palette ramp extremes.
